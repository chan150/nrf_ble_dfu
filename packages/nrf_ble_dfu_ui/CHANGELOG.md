## 1.0.0
* **Initial Release**: Split from `flutter_nrf_ble_dfu` into a decoupled architecture.
* Contains Flutter UI widgets (`DfuFileSelect`, `BleEntrySetup`, `AutoBleDfu`, `BleConnectedDevice`, `DfuProgress`, `BleDeviceSelect`, `LogConsole`).
* Includes SQLite database persistence for logs and history logs.
* Includes SharedPreferences for custom presets storage.
